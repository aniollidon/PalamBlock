# Guia ràpida per a professors nous

Aquesta guia t'explica les dues pantalles principals que faràs servir per supervisar els alumnes, especialment durant un **examen**.

---

## Navegadors

Aquesta pantalla et permet **veure què fan els alumnes al navegador** en temps real.

### Què hi veus?

Quan entres a Navegadors, el primer que has de fer és seleccionar un **grup** al desplegable superior dret, pel carro d'examens cal entrar al grup *Examens*. Un cop seleccionat, veuràs una llista amb tots els alumnes del grup i, per cada alumne, **totes les pestanyes que té obertes** al navegador.

Cada pestanya mostra:
- La **icona** del lloc web (favicon)
- El **títol** de la pàgina
- La **URL** (adreça web)

### Què pots fer?

#### 1. Tancar una pestanya
Fes clic a la **X** d'una pestanya per tancar-la remotament al navegador de l'alumne.

#### 2. Bloquejar una web (avançat)  
> ⚠️ Els bloquejos són permanents i continuaràn pel professor que vingui després (a no ser que s'indiqui el contrari). Caldrà anar alerta. 

Fes **clic dret** sobre una pestanya i tria:
- **Bloqueja alumne**: crea una norma que bloqueja aquesta web només per a aquest alumne.
- **Bloqueja grup**: crea una norma que bloqueja aquesta web per a tot el grup.

En crear la norma pots triar entre:
- **Bloca**: la pàgina no es podrà obrir.
- **Només avís**: la pàgina es mostrarà però amb un avís.

També pots afinar el bloqueig per **host** (domini), **path** (ruta concreta), **paraules al títol** o **categories**. Pots posar una **durada** perquè el bloqueig s'elimini automàticament en acabar l'examen.

#### 3. Fer una llista blanca (avançat)  
> ⚠️ Es recomanable donar-lis una durada que abarqui només l'examen. 

Les llistes blanques són molt útils per permetre internet a pàgines determinades. 

Si feu servir webs que requereixen login de Google caldrà afegir Google-Workspace > Profile. Perquè sinò l'alumen no podrà entrar. 

#### 4. Activar o desactivar filtres
Al botó d'estat del grup pots triar entre:
- **Filtre actiu**: les normes de bloqueig estan aplicades.
- **Filtre desactivat**: no s'aplica cap bloqueig (navegació lliure).
- **Tot bloquejat**: tots els navegadors queden completament bloquejats.

> ⚠️ Per un examen, el més habitual és tenir el **Filtre actiu** o bloquejar completament internet.

#### 5. Consultar l'historial
Fes clic al botó **Historial Web** d'un alumne per veure tot el seu historial de navegació. Molt útil per saber què ha fet un alumne.


### Resum per a examen

| Acció | Com es fa |
|---|---|
| Veure què fan | Seleccionar grup i mirar les pestanyes |
| Tancar una pestanya | Clic a la X de la pestanya |
| Bloquejar una web | Clic dret > Bloqueja alumne / Bloqueja grup |
| Activar filtres | Botó d'estat > Filtre actiu |
| Consultar historial | Botó Historial Web de l'alumne |

## Pantalles

Aquesta pantalla et permet **veure les pantalles senceres** dels ordinadors dels alumnes i **enviar contingut** a les seves pantalles.

### Què hi veus?

En seleccionar un grup, veuràs una **quadrícula amb miniatures** de la pantalla de cada alumne. Cada miniatura es va actualitzant en viu.

### Què pots fer?

#### 1. Veure la pantalla d'un alumne en gran
Fes clic al botó del **cursor** (✥) per obrir la pantalla de l'alumne a **pantalla completa**, on també podràs interactuar-hi amb el ratolí i el teclat si cal.

#### 2. Apagar una màquina
- **Botó vermell (⏻)** a la miniatura: apaga només aquell ordinador.
- **Botó "Apagar tots"** a la barra superior: apaga totes les màquines del grup.

#### 3. Emetre contingut als alumnes
Fes clic al botó **"Emet al grup"** per obrir la barra lateral d'emissió. Tens tres opcions:

- **Emet la teva pantalla**: comparteix la pantalla del teu ordinador amb tots els alumnes del grup. Ideal per mostrar instruccions, un enunciat o una correcció.
- **Emet alumne**: selecciona un alumne i emet la seva pantalla a tots els altres (útil per mostrar un exemple).
- **Emet un enllaç (URL)**: envia una pàgina web a totes les pantalles. Pots triar si vols que els alumnes hi puguin interactuar o no.
- **Emet un missatge**: envia un missatge de text que es mostra temporalment a les pantalles. Pots configurar quants segons dura (0 = no desapareix fins que el treguis).

#### 5. Aturar una emissió
Quan estiguis emetent, apareixerà una previsualització a la barra lateral amb un botó **"Atura l'emissió"**. Fes-hi clic per deixar d'emetre.

### Resum per a examen

| Acció | Com es fa |
|---|---|
| Veure pantalles | Seleccionar grup i mirar la quadrícula |
| Veure un alumne en gran | Botó del cursor (✥) |
| Apagar una màquina | Botó vermell (⏻) |
| Apagar totes | Botó "Apagar tots" |
| Mostrar instruccions | Emet al grup > Emet la teva pantalla |
| Enviar un enunciat | Emet al grup > Emet un enllaç |
| Enviar un avís | Emet al grup > Emet un missatge |

---

## Consell final per a examen

1. Abans de començar, comprova a **Navegadors** que tots els alumnes estan connectats i amb el **Filtre actiu**.
2. Durant l'examen, vigila les pestanyes a **Navegadors** i les pantalles a **Pantalles**.
3. Si veus alguna web sospitosa, **bloqueja-la** amb clic dret des de Navegadors.
4. Si necessites donar instruccions a tothom, fes servir **Emet al grup** des de Pantalles.
